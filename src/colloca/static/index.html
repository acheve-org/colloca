A general-language base corpus per language gives small corpora something to be compared with: it is the default reference for keyness and adds “per million in general language” columns to frequency and collocations. It is kept apart from your own corpora, so it never dilutes their concordances or counts.

Fill it with sentence files (one sentence per line; Leipzig Corpora Collection files work as they are, check their licence). Files up to 25 MB can be uploaded here; for larger ones use colloca-import-reference (see the README). Sentences are shuffled in those corpora, so the “Docs” columns are meaningless for the base corpus.
